## Что работает
- API: `https://api.halemoney.com`, сервер Hetzner CAX11 `2.31.201.103`, код деплоится `infra/deploy.sh`.
- SSH открыт только для текущего IP. Если не подключается: `infra/open-ssh.sh` (токен Hetzner в Связке ключей).
- Импорт monobank завершён, личные данные загружены, бэкап в Object Storage, полное восстановление проверено.
- Для восстановления на Mac нужен `PSQL="docker run --rm -i --network=host postgres:16 psql"`, локальный psql слишком старый.
- iPhone: сборка Release через Xcode и бесплатный Personal Team, подпись действует 7 дней (установлено 3 ноября). Команда из `apps/mobile`: `npx expo run:ios --device iPhone --configuration Release --no-bundler` на Node 22. Push отключён локально в `ios/Hale/Hale.entitlements`, файл git-ignored: после `expo prebuild` проверить его и `ENABLE_USER_SCRIPT_SANDBOXING = NO`.
