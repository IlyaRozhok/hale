# Сводки по дням

По файлу на день, `ГГГГ-ММ-ДД.md`. Пишет ведущий агент в конце прогона `/hale-day`; `/hale-more` дописывает раздел «Дополнительно». Состав сводки описан в `.claude/skills/hale-day/SKILL.md`, раздел 6.

В каталог дня `ГГГГ-ММ-ДД/` кладутся только макеты, которые ждут решения владельца; после решения макет остаётся, пока задача не сделана. Снимки экранов уходят владельцу сразу после проверки экранов и в репозиторий не коммитятся (решение владельца 11 ноября 2026; снимки первого прогона остались как есть).
