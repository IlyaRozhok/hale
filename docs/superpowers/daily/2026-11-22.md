1. **А24. Когда лимит превышается почти каждый день** — макет `docs/superpowers/daily/2026-11-22/maket-a24-temp.png`:
   - **А (рекомендую):** дни выше лимита — одна тихая точка, красное только у сегодняшнего перерасхода; под лимитом песочная строка «В таком темпе хватит до … — доход …», только когда денег не хватит; по нажатию — окно «Темп трат»;
